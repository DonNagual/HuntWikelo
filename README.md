 # Hunt Wikelo

**Hunt Wikelo** ist ein kleines, nicht-kommerzielles Browser-Fanprojekt im *Star Citizen*-Universum.

Das Spiel läuft direkt im Browser und wurde mit **HTML, CSS und JavaScript** umgesetzt.

## 🎮 Spielen

👉 **[Hunt Wikelo starten](https://donnagual.github.io/HuntWikelo/)**

## 🕹️ Spiel

Wähle zwischen:

* **Cutlass**
* **Hull-C**

und begib dich auf die Jagd nach **Wikelo**.

Das Projekt befindet sich weiterhin in Entwicklung.

## ⌨️ Steuerung

| Taste | Funktion |
|---|---|
| `W` | Schub nach vorn |
| `A` / `D` | Nach links / rechts wenden |
| `Space` | Feuer |
| `Enter` | Start / Pause / Weiter |
| `Escape` | Pause / Ende |

## 🛠️ Technik

* HTML5
* CSS
* JavaScript
* Canvas
* GitHub Pages
